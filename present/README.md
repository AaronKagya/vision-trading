# Vision Trading AI — presentation demo

This UCU demonstration displays archived 2024–2025 research results. Not live AI trading or an investment recommendation.

The presentation has six guided pages with an interactive eight-model, three-market comparison, provenance and holdout results, and links to the original research, replay and prospective audit. The [offline backup ZIP](https://github.com/AaronKagya/vision-trading) is distributed separately.

Original research: https://github.com/AaronKagya/vision-trading
